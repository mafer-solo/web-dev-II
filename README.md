# My Tech Journey

## Reflection

Creating this website helped me practise HTML, CSS and JavaScript. The easiest part was adding information about myself, my skills, my university internship and my experiences in South Korea and Japan.

The most challenging part was adjusting the colours, resizing images and making the dark mode readable. I learned how CSS selectors affect the appearance of different elements. Organising images and videos into separate folders also helped me understand file paths.

I added a theme switcher and an interactive photo gallery using JavaScript events and DOM manipulation. I tested my website in Safari, checked the browser console and made adjustments to improve the layout and functionality.

During Web Development II, I would like to improve my JavaScript skills, particularly understanding event handling, creating more interactive features and becoming more confident in identifying and fixing errors independently.

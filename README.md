# My Tech Jorney

## Reflection
Creating this website helped me practice HTML, CSS an JavaSript. The most straightforward part was adding information about myself, my skills, my university internship and my experiences in South Korea and Japan.
The most challenging part was adjusting the colours, sizing the photos and making the dark mode readable. I learned that CSS selectors can affect which styles are applied. Organising images and videos into separate folders also helped me understand file paths.
I added a theme button  and photo control gallery using JavaScript events and DOM updates. I tested the interactions in Safari and checked the console while investigating problems.
I would like to improve my JavaScript skills so I can create more useful interactions and understand how to find and fix errors independently.
